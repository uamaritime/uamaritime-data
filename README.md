# uamaritime-data

Active tropical cyclone data (`storms.json`) for the free Nautical Distance Calculator at https://uamaritime.com/distances/.

A GitHub Actions workflow (`.github/workflows/storms.yml`) refreshes it about every 3 hours from GDACS (Global Disaster Alert and Coordination System, EC JRC / UN OCHA), which republishes JTWC, NHC and regional warnings. Indicative only, not for navigation.
